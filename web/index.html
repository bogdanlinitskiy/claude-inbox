New session

Starts Claude Code in its own tmux session, in auto mode. It shows up here and alerts you when it needs you.

Repositories, one session each

An existing branch is checked out as it is; a new one starts from the default branch. The worktree goes next to the repositories, in a folder ending in -worktrees, and stays after the session closes.
